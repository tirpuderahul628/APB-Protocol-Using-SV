# APB Protocol — SystemVerilog
 
SystemVerilog design/testbench for the AMBA APB (Advanced Peripheral Bus) protocol, compiled and simulated using **Synopsys VCS**.
 
## Status
✅ 10/10 test cases passed
 
## Run
```bash
vcs -sverilog -full64 -f filelist.f -o simv
./simv
```
 
## Requirements
- Synopsys VCS
